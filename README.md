# Mitigating Object Hallucinations in Large Vision-Language Models using Subspace Intervention Techniques

Welcome! This repository is dedicated to tracking strategies, experiments, and resources focused on reducing object hallucinations in Large Vision-Language Models (LLMs). This work is done as part of my Independent Project at Visual Conception Group IIIT Delhi under the guidance of Prof. A V Subramanyam.

To keep things lightweight here, the documentation and some code runs are hosted externally.
